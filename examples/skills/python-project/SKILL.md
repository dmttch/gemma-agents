# Projet Python avec uv

Utilise ce skill pour inspecter, modifier et vérifier un projet Python.

1. Lis pyproject.toml et les instructions locales avant toute modification.
2. Repère les tests existants et crée un plan pour une tâche complexe.
3. Utilise uv run pytest pour les tests et uv run ruff check pour le lint.
4. Lis les fichiers concernés puis réalise une modification ciblée.
5. Vérifie le résultat et cite les commandes effectivement exécutées.

Les dépendances doivent être préinstallées par l'utilisateur : le sandbox est hors
ligne. Si elles manquent, signale le blocage. Ce skill n'accorde aucune permission
supplémentaire et ne dispense jamais d'une approbation demandée par le runtime.
