Gemma Agents
============

Agent de développement local pour macOS Apple Silicon, piloté par un modèle
Ollama installé. Il explore un workspace, prépare ou applique des modifications,
exécute des validations approuvées et conserve les conversations dans SQLite.

Le code est distribué sous licence Apache-2.0. Les modèles possèdent leurs propres
licences. Lisez le périmètre de sécurité avant d'autoriser l'exécution de commandes.
