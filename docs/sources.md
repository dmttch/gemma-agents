# Références officielles

Ces références ont été consultées pour les choix d'implémentation et de livraison.

- [Sphinx autodoc](https://www.sphinx-doc.org/en/master/usage/extensions/autodoc.html) : import du code et extraction des docstrings.
- [Sphinx Napoleon](https://www.sphinx-doc.org/en/master/usage/extensions/napoleon.html) : docstrings Google.
- [Read the Docs : configuration v2](https://docs.readthedocs.com/platform/stable/config-file/v2.html) : Python 3.14, installation uv et construction stricte.
- [Read the Docs : personnalisation](https://docs.readthedocs.com/platform/stable/build-customization.html) : groupes de dépendances et pipeline.
- [uv avec GitHub Actions](https://docs.astral.sh/uv/guides/integration/github/) : installation et lockfile en CI.
- [uv : installation d'outils](https://docs.astral.sh/uv/guides/tools/) : environnements isolés.
- [SQLite dans Python](https://docs.python.org/3/library/sqlite3.html) : transactions et API de sauvegarde.
- [fcntl dans Python](https://docs.python.org/3/library/fcntl.html) : verrous consultatifs.
- [Ollama : API](https://docs.ollama.com/api) : modèles, métadonnées et appels.
- [Ollama : spécification](https://github.com/ollama/ollama/blob/main/docs/openapi.yaml) : schéma de capacités des modèles.
- [GitHub : runners](https://docs.github.com/en/actions/how-tos/write-workflows/choose-where-workflows-run/choose-the-runner-for-a-job) : architecture des runners macOS.
- [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0) : texte officiel de la licence approuvée.
